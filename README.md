# Brandon Sanderson's Cosmere

A tribute page about the Cosmere, the fictional universe created by Brandon Sanderson, built for the freeCodeCamp "Build a Tribute Page" project (Responsive Web Design Certification).

## About The Project

The page provides information about the Cosmere and displays several books of the universe. It was built to the freeCodeCamp assignment's user stories: a tribute page structure (`main`, `title`, `img-div`, `image`, `img-caption`, `tribute-info`, `tribute-link`), a responsively resizing, centered image, and an external link for further information.

The header has a moving background and includes a photo of Brandon Sanderson; books are displayed with simple scaling effects on hover; the footer links to the author's website and to the freeCodeCamp project.

### Built With

- HTML5
- CSS3

## Getting Started

Open the HTML page in a browser.
